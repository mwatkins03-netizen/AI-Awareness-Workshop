# AI Literacy Activities — Academic Innovation

Faculty-development landing page showcasing six interactive AI-literacy
activities, by Marc Watkins (Academic Innovation, University of Mississippi).

## How to publish on GitHub Pages

1. Create a new repository (any name, e.g. `ai-literacy-activities`).
2. Upload **everything in this folder** to the repository root, keeping the
   structure intact:
   ```
   index.html
   styles.css
   .nojekyll
   assets/workshop-2000.jpg
   ```
   (The `.nojekyll` file tells GitHub to serve the files as-is.)
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch** → branch `main` →
   folder `/ (root)` → **Save**.
5. Wait ~1 minute. Your page is live at
   `https://<your-username>.github.io/<repo-name>/`.

### Common gotchas
- The main file **must** be named `index.html` (all lowercase, no spaces).
- Keep `assets/` as a folder next to `index.html` — don't flatten it.
- If you see the old version after updating, hard-refresh (Cmd/Ctrl + Shift + R).

The six activities are embedded as live previews from their own GitHub Pages
URLs, so an internet connection is needed to see them load on hover.
